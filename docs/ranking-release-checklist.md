# コトダマ杯 公開前チェックリスト

## この文書の前提

- ランキング名は「コトダマ杯」で、サーバーが確認したオンライン対戦の週間勝利数を順位に使う。
- プレイヤーIDと認証用トークンは無作為に発行し、表示名は安全な言葉の一覧からサーバーが自動生成する。
- 週間の勝利数・敗北数・対戦相手数、週間順位、対戦記録、上位3名の入賞・受賞履歴を、匿名プロフィールが削除されるまで保持する。
- 対戦ルームと定型スタンプは15分以内に削除する。
- 上位3名の入賞記録は匿名プロフィールを本人が削除するまで残し、金・銀・銅の王冠とオーラは次の大会期間中だけ表示する。
- 上位100名の自動生成名、順位、勝利数、ご縁の人数をランキング参加者へ表示し、最後に読み込んだランキングはオフライン表示のため端末内にキャッシュする。
- 自由チャット、利用者が入力する名前・文章・画像、広告、行動解析、トラッキング、データ販売は行わない。

実装がこの前提と異なる場合は、公開前に `privacy.html`、`support.html`、ストア申告を実装に合わせて修正する。

## アプリ内で確認すること

- [ ] 保護者にも分かる場所からプライバシーポリシーとサポートページを開ける。
- [ ] 初めて匿名プロフィールを作る前に、保存する情報、ランキングでほかの利用者へ表示する情報、対戦相手へ表示する自動名と前回入賞を説明し、「同意して参加する」「ランキングに参加せず対戦だけ使う」を選べる。後者でも、対戦ルームへ送る情報と15分以内の削除を事前に説明する。
- [ ] コトダマ杯の「ランキングの記録を削除」で、サーバーの匿名プロフィール、週間戦績、対戦記録、入賞・受賞履歴の削除APIを呼ぶ。B リセットはキャラクターだけをタマゴへ戻す。
- [ ] サーバー削除が成功したことを確認してから完了表示を出す。
- [ ] オフラインや通信失敗時は「サーバー側はまだ削除されていない」ことと再試行方法を表示する。
- [ ] 削除相談に使える問い合わせ用IDは表示するが、認証用トークンは画面やログに表示しない。
- [ ] 他人の問い合わせ用IDや入賞履歴をランキングAPIから取得できない。公開ランキングには自動生成名、順位、勝利数、ご縁の人数だけを返す。
- [ ] 「ランキングの記録を削除」で端末内のランキングキャッシュと期間限定の表彰表示も削除する。
- [ ] 名前の候補と定型スタンプを子ども向けに確認し、自由入力へ抜ける経路がないことをテストする。
- [ ] 同じ相手との繰り返し対戦など、ランキングの不正対策をテストする。
- [ ] 外部配信のフォントなど、通常起動時に不要な第三者通信を行わない。必要な通信がある場合は、ポリシーとストア申告へ正確に反映する。
- [ ] Cloudflareを通信・保管基盤として使うことをストア申告と審査メモへ反映し、公開前に契約・データ処理条件が子どもを含む対象年齢と提供地域に適合することを確認する。

## Google Play Console

- [ ] 対象年齢に子どもが含まれる申告と、実際のアプリ内容を一致させる。
- [ ] データセーフティで、プレイヤーID、ゲームの操作・戦績など、実際にサーバーへ送るデータを漏れなく申告する。
- [ ] データの収集目的、暗号化、削除方法、保持方法を実装どおりに回答する。
- [ ] IARCコンテンツレーティング質問票でランキングと固定スタンプによる利用者間の交流を正確に申告し、自由チャット・自由入力名・画像共有がないことを審査メモへ記載する。
- [ ] ストア掲載情報から最新のプライバシーポリシーへアクセスできることを確認する。
- [ ] アプリ内のポリシーとオンライン対戦サーバーの `/privacy` の内容を一致させる。
- [ ] 子ども向けアプリに適用される要件を公開直前に再確認する。

参考: [Google Play ファミリー ポリシー](https://support.google.com/googleplay/android-developer/answer/9893335?hl=ja)

## App Store Connect

- [ ] App Privacyで、ユーザーIDとゲームプレイ内容など、実際にサーバーへ送るデータを実装どおりに申告する。
- [ ] 匿名プロフィール作成前の説明と同意、Bリセットによる撤回・削除が実際に動くことを確認する。
- [ ] アカウントを作らなくても匿名プロフィールを生成する設計について、削除手段と問い合わせ先を審査メモに簡潔に説明する。
- [ ] 年齢区分、子ども向けの内容、自由形式のユーザー生成コンテンツがないことを実際の機能と一致させ、固定スタンプによる交流は審査メモで説明する。
- [ ] Kids Categoryを選ぶ場合は、アプリ外リンクやメール起動を保護者向け領域とペアレンタルゲートの内側に置く。
- [ ] 審査用アカウントが不要でも、審査担当者が初回同意、上位100名のランキング表示、3種類の固定スタンプ、Bリセットによる撤回・削除、削除失敗時の表示を確認できる手順を審査メモに書く。
- [ ] プライバシーポリシーURLとサポートURLが公開され、アプリ内の説明と一致していることを確認する。

参考: [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)
